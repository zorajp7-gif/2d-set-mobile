# 2D SET Live Mobile App

Android WebView wrapper for the live 2D SET backend.

Default API:
https://twod-set-backend-2.onrender.com/api/live

Features:
- Dark mobile UI
- Current 2D
- SET Index / SET Value
- Market status
- Source timestamp
- 5-second refresh
- History (latest 50)
- Settings with editable API URL
- Test Connection
- Android WebView wrapper
